Methodology

What the numbers are, and what they are not.

← Rankings

v2: schedule-adjusted EPA margin (default)

Expected points added (EPA) per play comes from nflverse play-by-play data. For each team we take every regular-season scrimmage play (pass or run, no penalty-only plays, no two-point tries) with a non-null EPA, and compute:

  • Raw offensive EPA: play-weighted mean EPA on the team's offensive plays.
  • Raw defensive EPA: play-weighted mean EPA the team allowed. Lower is better.

We then adjust for opponents over 20 iterations. Each iteration, a team's offense is its raw EPA minus the play-weighted mean adjusted defensive EPA of the defenses it faced; its defense is raw EPA allowed minus the play-weighted mean adjusted offensive EPA of the offenses it faced. After every iteration both sides are re-centered so the league mean of the adjusted values equals the league mean of the raw values. The rating is v2 = adj_off − adj_def, in EPA per play; higher is better.

What it is not: it is not DVOA, it does not adjust for injuries, garbage time, weather or home field, and it is not a betting model. It is a transparent descriptive ranking of what teams have done so far.

Legacy v1 FUNCTION

The original ranking was a spreadsheet formula (NFL2022 workbook). It is kept as a secondary view. For one offense, or one defense (using the opponent versions of the same stats):

FUNCTION =
  ((pts_per_drive * (fg_pct + xp_pct))
   + (yards_per_play * (first_down_pct + third_down_rate)))
  * (score_pct + (100 - turnover_pct))

net FUNCTION = offense FUNCTION - defense FUNCTION   (higher is better)

The column correction

The notes extracted from the workbook described the kicking term as "FGA+FGM" and one of the drive terms as "EXP". Those labels are wrong. The cells reproduce every 2022 FUNCTION value (max absolute error about 1e-10) only with:

TermWorkbook columnNot
fg_pct + xp_pctkicking FG% and XP% (Numbers columns Q and T)FGA + FGM
first_down_pctcalculated 1stD% (Numbers column AC)EXP (unused by the formula)

v1 follows the cells that were actually sorted, not the prose. A test recomputes all 64 offense/defense FUNCTION values and the 32 net values from the exported 2022 CSVs.

The scale quirk

Scales are kept exactly as stored in the workbook. fg_pct, xp_pct and third_down_rate (3D%) are fractions (0.415, because that is how the Numbers paste stored them). first_down_pct, score_pct and turnover_pct are percentage points (30.91, 36.8, 11.1). They are not "fixed", since doing so would change the ranking.

Reading a negative FUNCTION

Net FUNCTION is offense minus defense. A negative value means the team's defensive FUNCTION is larger than its offensive FUNCTION: opponents' production against it outweighs its own. For defense, a lower FUNCTION is better, which is why the net is a subtraction.

nflverse approximations for live legacy inputs

The 2022 workbook used Pro Football Reference tables. Live seasons derive the same eight inputs from nflverse play-by-play (regular season only). Defense values are the same statistics over plays and drives where the team is the defense. Expect magnitudes in the same ballpark, not identical numbers.

  • Scrimmage plays: play_type pass or run, excluding no-plays, rows without a possession team, and two-point attempts.
  • yards_per_play: sum of yards gained / scrimmage plays.
  • first_down_pct: 100 × (pass + rush + penalty first downs) / scrimmage plays. If those columns are missing, 100 × first_down / plays.
  • third_down_rate: converted / (converted + failed), as a fraction; 0 if none.
  • fg_pct, xp_pct: made / attempts, as fractions; 0 if no attempts.
  • Drives: unique (game, possession team, fixed drive id), ignoring kickoffs and null drive ids.
  • score_pct: 100 × drives with an offensive touchdown or made field goal / drives. nflverse's drive_ended_with_score also flags defensive scores (pick-sixes, safeties), so it only counts when the drive result is a touchdown or field goal.
  • turnover_pct: 100 × drives containing an offensive interception or lost fumble / drives.
  • pts_per_drive: offensive points (6 per offensive TD, 3 per FG, 1 per XP, 2 per two-point conversion) / drives. Defensive and special-teams scores are excluded.

Data

All data is free: nflverse play-by-play, schedules and team metadata, fetched with the nfl_data_py package. Nothing is scraped, and Pro Football Reference is not used for live data. Records and point differential come from played regular-season games only.
